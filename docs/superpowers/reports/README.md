## 읽을 때 주의

측정값에는 **어떤 코퍼스로 쟀는지**가 붙어 있어야 한다. 이 저장소는 짧은
픽스처(청크 30~77자)로 재고 "변화 없음"이라 결론 낸 적이 두 번 있다
(`RERANK_MAX_CHARS`, 그리고 `CAND_K`). 실제 문서는 청크 중앙값이 1,295자이고,
리랭킹 비용도 검색 난이도도 쪽 개수가 아니라 **쪽 길이**에 좌우된다.
길이 감각이 필요한 실험은 `eval/corpora/deep.py` 나 `longchunk.py` 로 할 것.
